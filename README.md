# Android APK Build Template

This is a minimal Android project that builds an APK using GitHub Actions.

## Build in GitHub
1. Upload/extract this folder into your repository.
2. Open the **Actions** tab.
3. Select **Android APK Build** and run it (or push a commit).
4. Open the successful workflow run and download the `app-debug-apk` artifact.

This template is a clean starter app, not a port of any commercial game. Add only code/assets you have rights to use.
